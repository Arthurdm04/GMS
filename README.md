# 🌱 Grupo GMS - Site Institucional

Este é o site institucional do **Grupo GMS**, desenvolvido como uma landing page simples e objetiva para apresentar a empresa, seus cultivos, história e contatos.

---

## 📌 Seções do Site
- **Início** → Apresentação com chamada principal.
- **Sobre Nós** → História do grupo, linha do tempo, Missão, Visão e Valores.
- **Vídeos** → Reportagens e aparições na mídia.
- **Cultivos** → Principais culturas trabalhadas (soja, milho, sorgo...).
- **Infraestrutura** → Estrutura física (silos, galpões, etc.).
- **Unidades** → Locais de atuação.
- **Contato** → Telefone, WhatsApp e redes sociais.

---

## 🛠️ Tecnologias Utilizadas
- **HTML5** → Estrutura do site.
- **CSS3** → Estilização com responsividade.
- **Bootstrap** → Auxílio no grid e responsividade.
- **Git & GitHub** → Controle de versão e hospedagem do código.

---

## 🚀 Funcionalidades Extras
- Ícones interativos de redes sociais (Instagram e WhatsApp).
- Área de vídeos para dar mais credibilidade.
